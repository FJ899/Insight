# Insight — High-Value Insight Ledger

This file preserves high-value conceptual material that should survive individual AI sessions.

It is deliberately **not** a decision log and **not** current state.

```text
INSIGHT != DECISION
INSIGHT != IMPLEMENTATION
INSIGHT != PROVEN FACT
```

## Status vocabulary

- `OPEN` — valuable idea, not yet tested or adopted.
- `TEST` — explicitly being tested.
- `PROMOTED` — moved into a decision, protocol, experiment, or current-state mechanism.
- `PARKED` — intentionally retained without current action.
- `SUPERSEDED` — replaced by a better formulation or evidence.
- `FALSIFIED` — evidence materially contradicts it.

## INSIGHT-2026-08-25-006 — Conversation history is not usable knowledge state

**STATUS:** OPEN

**SPARK:**

A conversation can contain a valuable insight and still functionally lose it if the insight remains buried in session history and is not promoted into a durable, discoverable form.

**WHY IT MATTERS:**

Raw archiving alone solves loss of bytes, not loss of meaning. Session harvest and an explicit insight ledger are separate requirements.

**RELATED PRINCIPLE:** history is a log of changes, not compiled current state.

---

## INSIGHT-2026-08-25-007 — Technical detail should be demoted, not deleted

**STATUS:** PROMOTED

**SPARK:**

The solution to implementation noise is not to ask the AI to think less technically. Preserve technical detail as evidence/trace, while giving conceptual insight its own visible layer.

**WHY IT MATTERS:**

Aggressive summarization can destroy exactly the reasoning/provenance needed later, while unfiltered technical narration can hide the conceptual breakthroughs worth retaining.

**PROMOTED TO:** `ARCHIVE_PROTOCOL.md` presentation rule.
