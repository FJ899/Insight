# SESSION_HARVEST_v1

Use after a material AI session to preserve what would otherwise remain trapped in the chat.

The harvest is **not** a substitute for RAW transcript and **not** automatically authoritative current state.

```text
SESSION_ID:
DATE:
SOURCE / CHAT POINTER:
RAW ARCHIVE STATUS: CAPTURED / PARTIAL / NOT CAPTURED
RELATED PROJECT / EXPERIMENT:
```

## 1. WHAT CHANGED

What is materially different in our understanding, state, or direction after this session?

Keep this short.

## 2. INSIGHT SPARKS

For each high-value insight:

```text
SPARK_ID:
RAW / VERBATIM FORMULATION:
WHY IT MATTERS:
EPISTEMIC STATUS: OPEN / INFERRED / TEST / PROMOTED / PARKED / SUPERSEDED / FALSIFIED
SHOULD PROMOTE TO INSIGHTS.md: YES / NO
```

Preserve exact AI wording when the wording itself contains unusually useful conceptual compression.

Do not flatten every spark into neutral administrative prose.

## 3. DECISIONS ACTUALLY MADE

Only decisions actually owned/accepted by the appropriate authority.

```text
DECISION:
OWNER:
EVIDENCE / BASIS:
WHERE RECORDED AS CURRENT STATE:
```

If no decision was made, write `NONE`.

## 4. OPEN HYPOTHESES

Ideas worth retaining but not yet proven or authorized.

Do not silently convert these into TODO or current architecture.

## 5. OPEN LOOPS / UNRESOLVED QUESTIONS

What remains genuinely unresolved?

Prefer questions whose answer could materially change direction.

## 6. TECHNICAL TRACE

Only the minimum pointers required for later reconstruction:

```text
REPO / BRANCH / SHA
FILES
PR / COMMIT / ARTIFACT
TEST / EVIDENCE POINTER
```

Avoid re-copying large implementation detail unless the detail itself is the insight.

## 7. PROMOTIONS

Record which items from this session were promoted into durable surfaces:

```text
INSIGHTS.md:
STATUS.md:
TODO.md:
DECISION RECORD:
EXPERIMENT PROTOCOL:
OTHER:
```

## 8. SESSION HANDOFF

```text

...
```

## Closeout questions

Before considering the harvest complete, ask:

1. What would be expensive to rediscover?
2. Which AI formulation materially changed the mental model?
3. Which idea is important but still only a hypothesis?
4. Did technical execution hide a more important conceptual result?
5. Is any insight still present only in the chat transcript?
