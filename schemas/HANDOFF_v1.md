# HANDOFF v1 — AKCJA / GDZIE / ODESŁAĆ

Use this format for material tasks and handoffs.

```text
AKCJA
[What exactly is being done.]
[Boundaries: what is explicitly not being done.]
[Completion condition / result if already completed.]

GDZIE
[Exact repository / branch / SHA / file / experiment / source set.]
[Mark PINNED or LIVE when relevant.]

ODESŁAĆ
[Exactly one next handoff required from the recipient.]
[Use NIC if no recipient action is required.]
```

## Rules

1. Do not combine several unrelated next requests under `ODESŁAĆ`.
2. Continue autonomously until a genuine Human authority boundary is reached.
3. Do not use `ODESŁAĆ` as ceremonial confirmation for already-authorized work.
4. If blocked, state the blocker in `AKCJA` and request only the single missing Human action or decision.
5. `GDZIE` must identify the actual working scope, not a vague project name.
